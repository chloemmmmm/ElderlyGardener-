# 康护园｜康复师远程训练管理后台

这是一个面向 UX / 产品设计作品集的 B 端概念原型。项目将课程汇报中的老年园艺锻炼方案，转译为康复师可用于远程查看、复盘和调整训练计划的桌面管理工作区。

> 边界说明：本项目使用虚构姓名与演示数据，不是医疗器械或真实临床系统，不提供诊断建议，也未经过临床验证。

## 核心路径

1. **工作台**：把“需要判断”的事项置于指标之前，按风险与时效展示证据。
2. **康复对象**：支持姓名、训练阶段、关注状态、计划状态筛选及分页。
3. **对象档案**：并列呈现训练阶段、计划、近期记录与人工干预。
4. **训练记录复盘**：严格区分系统事实、用户自述、数据不确定性和 AI 待确认建议。
5. **计划编辑器**：提供动作级参数编辑、字段差异摘要、确认弹窗、保存失败保留与恢复。

## 运行方式

需要 Node.js 20+ 与 pnpm。

```bash
pnpm install
pnpm dev
```

打开 `http://127.0.0.1:5173/`。

## 验证

```bash
pnpm test:run
pnpm typecheck
pnpm lint
pnpm build
```

自动测试覆盖领域逻辑、服务层、应用外壳、对象档案回归与工作台可访问性。演示接口由 MSW 在浏览器内提供，无需后端服务。

## 技术与设计资产

- React 19、TypeScript、Vite、TanStack Query
- Radix UI、Recharts、MSW
- Vitest、Testing Library、jest-axe
- `DESIGN.md`：视觉语言、token 与组件规则
- `UX-CONTRACT.md`：交互状态与 AI 能力边界
- `docs/superpowers/specs/`：经确认的产品规格
- `docs/superpowers/plans/`：实施与验证计划
- `outputs/screenshots/`：四张 1440px 作品集截图

## 数据与 AI 说明

- 所有姓名、训练记录和统计数值均为演示数据。
- AI 摘要由确定性本地规则生成，用于展示可信 AI 的信息架构，不调用外部模型。
- AI 只整理事实、标记冲突并生成待确认建议；不会自动改写训练计划。
- 保存失败演示可在计划编辑页右侧开启，用于展示错误恢复能力。
